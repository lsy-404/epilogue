# 向量存储性能子任务发现

- `_scanBin` 原来对每条记录分别读取 id 长度、id、维度和向量，共四次同步读取；现在将 id 与维度合并读取。在 12 条记录的回归场景中，读取次数从原算法的 49 次（1 + 12 × 4）降到实测 37 次（1 + 12 × 3），减少约 24%。
- `searchByVector` 原来会累积候选并周期性排序；现在以最小堆常驻至多 `topK` 项，扫描阶段为 O(n log topK)，仅在返回前排序至多 `topK` 项。
- `upsert` 未带 vector 的同路径更新会覆盖 `vecDim`，且任意 dirty flush 都会重写向量文件；现在保留已持久化维度并仅在向量新增、替换、删除或旧格式迁移时重写 `vectors.bin`。
- 直接用对齐的 `Float32Array` 视图计算磁盘向量余弦相似度，移除了每条记录到独立 scratch 的复制；缓冲区仍在扫描中复用。

- 第二轮实现以固定 256 KiB 缓冲顺序读取 EVB1，跨块时只复制当前字段到复用缓冲；不会载入整个文件。25,000 条 × 384 维（39,450,008 字节）查询中，临时旧实现实测 100,001 次 eadSync、869.5 ms；新实现 151 次、37.4 ms，均返回 8 条结果。
- 新增回归覆盖最大 65,535 维向量、65,535 字节 ID、模拟 97 字节短读取，以及尾部截断时安全忽略不完整最后记录。

- ector 字段有三态：字段缺失表示仅更新元数据并保留向量；有效向量表示替换；显式 null 或无效值表示删除向量。检索同时以 vecDim 过滤元数据已删除但尚未 flush 的残留 bin 记录。既有记录始终保留内部 id，避免外部 id 覆盖使 idIndex 残留旧映射。
